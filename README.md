# OMEGA Intelligence V2

Dashboard de análise estatística de crypto, forex e ações, sem saldo ou operações.

Render: Python, build `pip install -r requirements.txt`, start `uvicorn main:app --host 0.0.0.0 --port $PORT`.

Endpoints: `/`, `/health`, `/api/markets`. Atualização a cada 60 segundos. Fontes públicas sujeitas a indisponibilidade. Horários de mercado aproximados, sem feriados. Não contém IA treinada.
